# Кинолавка

Мини React-приложение — каталог фильмов со скидками, карточками товаров и корзиной.

## Возможности

- Каталог фильмов с карточками
- Страница каждого фильма с подробным описанием
- Скидки
- Итоговая сумма и очистка корзины


## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/`.
